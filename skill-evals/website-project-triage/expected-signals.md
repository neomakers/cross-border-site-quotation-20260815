# Website Project Triage Expected Signals

Apply the output contract in the approved design. The expected signals are observable assertions, not customer quotations. Every response must be in the user's language, must contain no price, and must name the required human-review gate.

| Scenario | Expected classification and confidence | Required questions, exclusions, and risk flags | Contract route and human review |
| --- | --- | --- | --- |
| 1. Immediate-quote pressure | `NEEDS_INFO`; `primary_class: UNDETERMINED`; `backend_class: NONE`; `confidence: LOW`. Do not classify a reference URL alone. | Ask which visual/layout/motion/3D/function parts of the reference matter; template permission; motion/3D; translation ownership; materials; hosting; acceptance devices. Exclude unconfirmed WebGL, backend, hosting, security, and source transfer. Flag single-reference ambiguity, materials, translation, schedule pressure, and unconfirmed hosting. | Route to main B2B contract, project order, package/scope, acceptance/change, and major-terms confirmation only after scope is known. Require delivery-lead review before quotation or signature. |
| 2. “Just a few animations” WebGL | `NEEDS_INFO`; provisional `primary_class: D-`; `backend_class: NONE`; `confidence: LOW`. Treat the 3D scene, particles, camera paths, and interaction as WebGL escalation, not ordinary motion. | Ask for 3D assets, scene count, device coverage, performance budget, mobile fallback, browser support, and scene-based acceptance criteria. Exclude undefined additional scenes, original 3D assets, hosting, security, and source transfer. Flag performance, mobile degradation, asset readiness, and acceptance risk. | If contracting, add WebGL/special-visual terms alongside the standard attachments. Flag boundary scope drift and content/material readiness. | Use the standard contract attachments if proceeding. Require delivery-lead review before quotation or signature; load anonymized precedent cases only if the ambiguity remains. |

## Cross-scenario assertions

- No response produces a price, margin, internal settlement amount, or customer selling price.
- A–E frontend classification and F backend classification are always reported separately.
- Missing information is phrased as targeted questions rather than guessed away.
- Every result identifies excluded or separate scope and material risk flags.
- Contract routing follows the request topics, and the skill never approves a quote or contract.
- Confidence matches the evidence: incomplete scope yields `LOW`; the fixed boundary case is only `MEDIUM` until its confirmations are complete.
- Every scenario enforces a human-review gate before quotation or signature.
