# 跨境电商独立站报价方案

> 本文档用于业务员与项目伙伴实时协作。价格均为人民币（CNY），可按客户实际需求更新。

## 核心原则

- **简单模板站的实际交付成本为 ¥1,000。**
- 对客户销售时，基础报价与域名、服务器、功能增项分开，避免低价项目无限加需求。
- 所有定制功能在需求确认后，以功能清单锁定价格和工期。

## 对外产品与建议报价

| 档位 | 面向客户报价 | 适用范围 | 交付边界 |
| --- | ---: | --- | --- |
| 简单模板站 | **¥1,980 起** | 现成模板、5 页以内、产品展示、联系表单、移动端适配 | 客户提供 Logo、文案、图片和产品资料；仅 1 次文字/图片修改；不含域名、服务器、翻译、商城、支付和定制设计 |
| 中级非模板站 | **¥6,800 起** | 独立首页设计、8 页以内、产品展示、询盘、轻动效 | 适合需要品牌感、产品结构和定制首页的客户；超出页面和功能按增项计费 |
| 高级动态定制站 | **¥15,800 起** | 动态交互、复杂动画、商城/支付、后台定制或接口对接 | 先做需求与交互方案，再以功能清单分项报价 |

## 简单模板站的成本与成交口径

| 项目 | 金额/处理方式 |
| --- | --- |
| 实际模板交付成本 | ¥1,000 |
| 建议客户报价 | ¥1,980–2,980 |
| 首年建站打包价（可选） | ¥2,980，含模板站、部署和首年基础服务器 |
| 次年续费参考 | ¥1,000 左右（服务器与基础运维） |

业务员话术：

> 基础展示模板站 1,980 元起；需要按品牌重新设计、扩充产品展示和页面结构，6,800 元起；涉及动态交互、动画、商城或系统接口，15,800 元起，按功能清单报价。

## 中高级项目增项价目

| 增项 | 建议报价 |
| --- | ---: |
| 额外模板页面 | ¥300–500 / 页 |
| 额外定制页面 | ¥500–1,000 / 页 |
| 双语配置 | ¥1,000–2,000 |
| 产品批量上传 | ¥500 起 |
| 商城/支付功能 | ¥2,000–5,000 |
| 高级动画效果 | ¥1,000–3,000 / 屏 |
| 第三方接口/API | ¥3,000 起 / 个 |
| 后台定制、复杂数据功能 | 单独评估，¥5,000 起 |

## 域名、服务器与运维

这些费用应单列或作为年度服务包，不应吞进低价建站费：

- 域名：¥100–300 / 年，按实际费用收取；
- 海外服务器及基础部署：¥800–1,500 / 年；
- 基础运维：¥500–1,000 / 年；
- 第三方插件、Shopify/WooCommerce 订阅、邮件及支付平台费用：客户实报实销。

## 付款与变更规则

- 付款节点：50% 启动款、40% 测试稿确认、10% 上线交付；
- 每档默认包含约定次数的修改；新增页面、功能或推翻页面结构属于需求变更，需重新报价；
- 客户未按时提供资料，工期相应顺延；
- SEO 只包含基础技术设置，不承诺自然排名、询盘量或销售额。

## 高级动态项目的报价方式

高级项目不做一句话总包。先收 **¥2,000–5,000** 的需求梳理与交互原型费，项目签约后可从开发总价抵扣；然后按以下方式报价：

`高级基础站 ¥15,800 + 动画效果 + 接口/支付 + 后台功能 + 服务器及第三方费用`
